# Solène Studio

A responsive photography studio website built as a student portfolio project using React, TypeScript, and AI-assisted development.

## About the Project

Solène Studio is a fictional photography studio created as a personal learning project. The website presents the studio's services, photography portfolio, and visual identity through a modern editorial-style design.

The main goal of this project was to practice frontend development, explore visual design implementation, and gain experience building a complete website with the help of an AI coding assistant.

**This was my first experience working with Claude Code.** I used Claude as a development assistant to help implement components, refine the layout, improve styling, and work through the development process. This project gave me an opportunity to explore AI-assisted coding as part of my learning workflow.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Modern editorial-inspired design
- Reusable React components
- Photography portfolio and service sections
- Interactive navigation and hover effects
- CSS animations and transitions
- Modular styling with CSS Modules
- Type-safe development with TypeScript

## Tech Stack

- **React** — UI development
- **TypeScript** — static typing
- **Vite** — development server and build tool
- **CSS Modules** — component-scoped styling
- **Claude Code** — AI-assisted development

## Design Approach

The visual direction combines _Fashion Editorial_ and _Clean Modernism_, featuring expressive typography, large photography, asymmetrical layouts, and a balanced palette of white, black, gray, and subtle warm-neutral accents.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository: https://github.com/BOgdanRoz/PhotoStudio

```bash
git clone <https://github.com/BOgdanRoz/PhotoStudio>
cd solene-studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

Run the linter:

```bash
npm run lint
```
